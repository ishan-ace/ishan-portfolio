# Ishan Sharma — Developer Portfolio

A responsive, single-file portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready for GitHub Pages.

## Before publishing
1. Open `index.html`.
2. Search for `YOUR_EMAIL@example.com` and replace it with your real professional email.
3. Replace the footer Contra, LinkedIn, and GitHub URLs with your profile URLs.
4. The portfolio includes Aurié Luxe Co., Hobbyz, ActiveEarth, and Automated Control Systems with live-site links. Confirm the descriptions accurately reflect your own contribution and that you have permission to showcase each project.
5. Review all service claims and keep only the skills you can demonstrate.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `ishan-portfolio`.
2. Upload `index.html` (and this README if you want).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The URL will look like `https://YOUR-USERNAME.github.io/ishan-portfolio/`.

No build tools or paid hosting are required.
